# Tugas 3 – Manajemen Produk

Aplikasi manajemen produk dibuat dengan React dan Vite sesuai materi Fundamental React. Data produk disimpan di state React selama aplikasi berjalan.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite di terminal.

## Fitur

- Menampilkan lima produk awal dalam kartu.
- Mencari produk berdasarkan nama.
- Menambah produk dengan validasi nama dan harga.
- Mengedit produk.
- Menghapus produk setelah konfirmasi.
- Menampilkan jumlah produk, jumlah hasil pencarian, dan notifikasi aksi.

## Pengujian

Jalankan aplikasi di browser dan periksa fitur daftar, pencarian, tambah, validasi, edit, dan hapus. Lampirkan screenshot hasil pengujian pada Pull Request.
