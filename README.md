# Tugas-3_PEMWEB-C_5027251118

## Ringkasan Perubahan
Membuat halaman Manajemen Produk menggunakan HTML, CSS, dan JavaScript. Fitur yang dibuat: daftar produk dalam bentuk kartu, pencarian berdasarkan nama, serta pop-up Tambah, Edit, dan Hapus produk dengan validasi harga harus lebih dari 0.

## Bukti Pengujian
| Skenario | Hasil yang Diharapkan | Hasil Aktual |
|---|---|---|
| Membuka halaman | 5 produk awal tampil, "5 produk" dan "Menampilkan 5 dari 5 produk" | Sesuai |
| Mencari "pen" | Pulpen, Penggaris, dan Penghapus tampil | Sesuai |
| Tambah produk dengan nama kosong | Muncul pesan "Nama produk wajib diisi.", produk tidak tersimpan | Sesuai |
| Tambah produk dengan harga 0 | Muncul pesan "Harga harus lebih dari 0.", produk tidak tersimpan | Sesuai |
| Tambah produk valid (Rautan, 2500) | Kartu baru muncul dengan ID 6 | Sesuai |
| Edit produk ID 2 | Form terisi data lama, perubahan tampil di kartu | Sesuai |
| Hapus produk ID 3 lalu klik Batal | Pop-up tertutup, produk tetap ada | Sesuai |
| Hapus produk ID 3 lalu klik Hapus Produk | Produk hilang dari daftar | Sesuai |
